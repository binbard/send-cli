02 / SHORT COMMANDS

Type less. Send more.

Choose a destination. Your message or file follows the same pattern every time.

SEND A FILE TO YOUR TELEGRAM CHAT
$ send tg report.pdf

Use your configured bot and remembered receiver. Send several files in one command, or add -m for a message.

03 / ONE TOOL, MANY ROUTES

Pick the right path.

Chat apps, nearby devices, and remote machines. Use the channel that fits the moment.

↗
01 / CHAT

Telegram

Send messages, photos, and files to your configured bot conversation. Open a terminal chat when you need to stay in the loop.

send tg report.pdf
●
02 / CHAT

WhatsApp

Link your account with a QR code, then message or send files to a remembered recipient.

send wa -m "On my way"
◎
03 / BROWSER

HTTP share

Open a temporary browser share for downloads, messages, and uploads on your local network.

send http report.pdf
↔
04 / PEER

Local network

Discover another send receiver and transfer files with its receiver token.

send lan --list
⌁
05 / DEVICE

Android / ADB

Push files to an authorized Android device, straight into its Downloads folder.

send adb report.pdf
>_
06 / REMOTE

SSH

Move files to a server using your installed OpenSSH client and existing keys.

send ssh user@host report.pdf

04 / YOUR DEVICES, CONNECTED

A new device.
Already feels like yours.

Transfer your Telegram setup and an existing WhatsApp linked session from a configured computer over a one-time encrypted local connection. No authentication files to copy by hand.

01

Offer from your configured device

send device offer
02

Join from the new device

send device join <host:port>
03

Enter the one-time pairing code

The code stays off the network and expires after five minutes by default.

ⓘ A transferred WhatsApp session is a copy of one linked identity. Use it on only one computer at a time; either copy may later require relinking.

05 / GET GOING

From install to done.

Start with a channel you already use. Add more when you need them.

  1. 01

    Install

    Use Scoop on Windows or the install script for your platform below.

    send doctor
  2. 02

    Connect a channel

    Set up your Telegram bot or link WhatsApp from your phone. The CLI walks you through it.

    send tg --setup
  3. 03

    Send something

    Once a receiver is remembered, you can send with a short command.

    send tg report.pdf

06 / TAKE IT WITH YOU

Ready when you are.

Install with Scoop on Windows, or use a platform script to install and update. Scripts verify release checksums, and uninstalling keeps your provider settings.

Browse releases ↗
▦

Windows

PowerShell · x64 and ARM64

Install with Scoop
scoop bucket add binbard https://github.com/binbard/scoop-binbard
scoop install binbard/send

Then use scoop update send to update or scoop uninstall send to remove it.

Or install with PowerShell
iwr https://send.binbard.org/install.ps1 -OutFile install.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
Uninstall the script install
iwr https://send.binbard.org/uninstall.ps1 -OutFile uninstall.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
